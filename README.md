## Structured Data Extraction from Unstructured Text (Python, Regex)

Parses a mixed-format text log to extract dates, IP addresses, donation records, URLs, and contact information using Python's regular expression module (re). The project focuses on pattern-based extraction and data cleaning –– pulling structured fields out of a single unstructured text source without any manual reformatting of the source data.
